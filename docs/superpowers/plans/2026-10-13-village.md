# 第六阶段实施计划：村庄、村民与委托

目标：保留农场经营状态往返村庄，交谈、接取、交付并领取一次性委托奖励，保存任务与好感度。

2026-10-13 用户美术选择：提供 NPC、房屋、公告栏 PNG，等待素材接入。画面与地图验收依赖这些图片，不能用已有角色或房屋占位替代。

分层方案：NPC/日程/对话与委托模板为类型化数据，规则模块处理好感度、每日委托、交付与一次性领取。GameState 添加村民关系、已交谈日期、委托与每日资源采集记录；已有 schemaVersion 4 存档先完整验证再迁移，禁止丢失背包、金币、农田和时钟。

委托规则：每天按日期种子选出一项作物交付和一项资源交付；未接取旧单移除，已接取单保留到完成。公告栏接取，向委托人完整提交要求物品后成为“已完成”，再领取金币与好感度；失败不扣物品，领取仅一次。进度读取真实背包数量。每位村民每天首次交谈加 1 好感度，上限 100；任务奖励读取模板。

执行顺序：

1. 编写失败测试，实现三个 NPC 配置、日程解析、交谈与好感度规则。
2. 编写失败测试，实现每日生成、接取、数量进度、原子交付、奖励去重及资源采集规则。
3. 扩展 GameState 与存档校验，验证 schema 4→5 保留原进度及非法任务/好感度拒绝。
4. 等 PNG 到位：记录来源、裁切与显示比例，创建 Tiled 村庄、TownScene、出入口和不同房屋，校验所有日程点与出生点碰撞。
5. 接入逐字对话、公告栏和任务面板、资源采集、商店及场景生命周期；测试往返不重建状态、村庄读档及跨天结算。
6. 完整工程检查与浏览器验收：农场→村庄→对话→接单→收集→交付→领取→保存→刷新恢复。
