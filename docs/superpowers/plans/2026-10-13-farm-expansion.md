# 第七阶段：农场经营扩展实施计划

> 执行方式：使用 executing-plans 与 test-driven-development，按下列四个交付顺序实现并验证。

目标：动物、建筑、采集和季节规则共用现有背包、经济及跨天系统，恢复后保留经营状态。
架构：配置 → 独立 domain 规则 → FarmScene 展示 / DOM 面板。GameState 使用 schemaVersion 6，历史 4、5 版本先完整校验再补默认扩展状态。只扩展现有接口，不迁移现有系统。
技术栈：既有 TypeScript / Phaser / Vite / Vitest，无新增依赖。
规格：用户第七阶段要求及 AGENTS.md。

## 规则与文件责任

1. 动物：`data/animals.ts` 配置鸡 150、牛 300 金币，鸡舍最多 4 只、谷仓最多 2 只；饲料 10 金币，一日一份。喂过的动物次日产一份，未收取产物保留，不叠加。饥饿度 0–100、好感度 0–100；不引入死亡或繁殖。`domain/animals.ts` 处理购买、喂食、收取及跨天。`scripts/import_animals.py` 保留原图与原始 RGBA 裁片，最近邻统一比例；`world/Livestock.ts` 展示，`ui/LivestockPanel.ts` 操作。
2. 建筑：`data/buildings.ts` 配置栅栏、路灯、长椅及价格 / 材料；`domain/buildings.ts` 网格占用校验、放置、移动、拆除返还。购买沿用商店的原子交易；移动保留原物直到目的地合法；满背包不拆除。`world/PlacedBuildings.ts` 动态碰撞及预览，`ui/BuildingPanel.ts` 管理；G 打开，E 在面前放置，Esc 取消。
3. 采集：`data/farmResources.ts` 定义木材、石料与野生蘑菇节点，`domain/gathering.ts` 处理数量、空间和按游戏日期刷新的原子采集。材料可出售或制作建筑；制作全部校验后扣材料。节点状态保存，读取不刷新。
4. 季节：作物配置适种季节，播种前验证；跨季清除不适种作物并保留耕地。春秋萝卜、春夏土豆与草莓、夏秋南瓜，冬季休耕。地面使用季节色调，树木复用用户春 / 秋原图，冬季采用冷色氛围，不生成新图、不声称具备雪地美术。

## 校验关注点

- 重复操作不得重复扣饲料、产出或扣款；背包满不丢动物产物与建筑。
- 建筑不得挡住玩家、入口、互动对象、采集节点、地图边界或现有物体；移动失败不丢原建筑。
- 当前版本缺字段应拒绝，旧版本先验证再迁移；存档非法状态不覆盖原存档。
- 场景切换不重置扩展状态；暂停、同一天重复结算不生产。
- 跨季日期与种植规则一致，读取旧进度不擅自删除已有作物。
